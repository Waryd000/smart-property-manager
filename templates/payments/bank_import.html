Required CSV format

Use UTF-8 comma-separated values with these exact column names:

reference,transaction_date,amount,narrative
EQ-REF-001,2026-11-20T10:15:00+03:00,250000,Incoming rent payment
reference — unique bank transaction reference
transaction_date — ISO 8601 date/time
amount — positive incoming amount in UGX
narrative — optional bank description
  • Maximum file size: 5 MB
  • Maximum 5,000 transaction rows
  • Debit and zero-value rows are rejected
  • Identical references are safely skipped; conflicting duplicates reject the entire file
  • All rows are imported together or none are imported
